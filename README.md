# LUMORA BEAUTY STUDIO — Premium Luxury Salon & Spa Website

A modern, responsive, and production-quality frontend website for **LUMORA BEAUTY STUDIO**, a fictional luxury beauty salon located in Bandra West, Mumbai, Maharashtra, India.

> **DEMO SHOWCASE NOTE:** This website is a concept showcase designed to demonstrate high-converting, premium web development capabilities for luxury salons, aesthetic studios, and spa businesses. Fictional business details and reviews are presented solely for presentation purposes.

---

## ✦ Key Design & Aesthetic Highlights

- **Luxury Palette:** Deep obsidian (`#141312`), warm champagne gold (`#C5A26C` / `#B89058`), soft ivory cream (`#FAF7F2`), and delicate rose/sand accents.
- **Typography:** Classic luxury editorial headings in *Playfair Display* & *Cormorant Garamond*, paired with modern, crisp UI typography in *Plus Jakarta Sans*.
- **Curated Photography:** High-resolution salon and treatment imagery across styling, hair spa, 24K gold facials, Mumbai bridal artistry, and luxury nail aesthetics.
- **Smooth Interaction:** Polished transitions, sticky glassmorphism navigation, interactive service tabs, Lookbook lightbox modal, and on-page appointment booking with immediate WhatsApp confirmation vouchers.

## ✦ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS with custom luxury color palette (`gold`, `cream`, `obsidian`, `sand`), bespoke scrollbar, and glassmorphism.
- **Icons:** Lucide React + custom inline SVGs for social media.
- **Typography:** Playfair Display, Cormorant Garamond, Plus Jakarta Sans.

## ✦ Getting Started

### 1. Install dependencies:
```bash
npm install
```

### 2. Run in development mode:
```bash
npm run dev
```

### 3. Build for production:
```bash
npm run build
```

### 4. Preview production build:
```bash
npm run preview -- --port 5173
```
